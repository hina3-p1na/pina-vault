# キャリア適性・組織適合基準

> 2026-07-13、ChatGPTメモリー（思想開示文）から抽出・整理。次の転職・案件アサイン・組織選択の**判断基準**として使う実務ノート。[[キャリア志向性と現在地]]が「今の到達点」を記録するのに対し、こちらは「個別の選択肢をどう評価するか」の判定基準集。

## 職能定義（軸）
> 現場の違和感・非効率・品質ブレ・責任曖昧を、業務フロー・基準・KPI・会議体・改善ロードマップに変換する構造設計人材。
>
> 一言で：**混乱を仕組みに変える人。属人性を標準化する人。期待値と提供品質のズレを構造で直す人。**

実装・定着・運用回収まで一人で背負う役割ではなく、責任者や実行部隊と接続しながら構造設計と改善推進を担う役割で最も価値が出る。

## グッドカンパニーの定義（組織を評価する軸）
- 提唱価値と提供価値がズレていない
- 顧客に対して誠実な期待値形成をしている
- 事業成長と提供品質が両立している
- 人月や未経験アサインに依存しすぎていない
- Push営業だけでなく、信頼・プロダクト・仕組みで勝とうとしている
- 顧客体験が属人的努力だけに依存していない
- 事業責任者や経営陣が「構造で勝つ」思想を持っている
- 現場の違和感や非効率を放置せず、仕組みに変換しようとする

この定義は「合意したバリューへの対価」という契約思想、[[ブランドは信頼の建築物である]]の「提唱価値と実態の一致」というブランド観と同根。

## 向いている職種領域
BizOps / RevOps / SalesOps / 営業企画 / Sales Enablement / GTM Ops / BPR・業務改革 / Sales Transformation / CRM・SFA上流コンサル / CX企画・サービス品質企画 / 事業推進・上流PMO

向いている業務の共通点：散らかった現実（複数部門・曖昧な課題）を構造化する／非効率・属人化・手戻りを仕組みで改善する／人を直接ケアするのではなく人が動ける構造を作る／営業・顧客・組織の品質を標準化する／経営や事業責任者の近くで論点整理する（ただし権限のない調整役は不可）。

## 向いていない職種・避けたいルート
フィールドセールス・AE／CSM（カスタマーサクセスマネージャー、個別顧客への長期伴走）／カスタマーサポート／営業事務・営業アシスタント／ピープルマネージャー専任／採用人事・HRBP（現場寄りの長期調整役としての意味で）／日常運用型PMO（進捗確認・催促・タスク回収が中心のもの）／現場サポート型SalesOps（CRM入力督促・相談窓口が主務のもの）／完全0→1の新規事業開発（泥臭く数を打ち検証し続けるタイプ）／営業支援会社・人材・BPOへの横滑り（現職の違和感を再生産するリスクが高いため原則非推奨）。

IS/BDR Managerは条件次第（KPI設計や仕組み化に染み出せるなら可、行動量管理・未熟メンバー育成伴走が主務なら不可）。
