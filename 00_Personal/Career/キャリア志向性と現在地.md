# キャリア方向性 — 意思決定フレームワーク

## 現在地（2026時点）
- プルーセル（営業代行）のディレクター（サブポジション）
- リブ・コンサルティング子会社
- 2名体制の第二ポジション

## 目指しているもの
**CRO / CSO / 事業責任者**
= ブランド・Revenue・顧客体験を統合できるポジション

### 中間目標
1. RevOps / BizOps として機能横断の設計経験を積む
2. GTM / Customer Transformation の実績を作る
3. "価値提供 → 信頼 → 継続 → 推奨" の循環を事業として証明する

## 意思決定の軸（何で会社・ポジションを選ぶか）
| 軸 | 重視する | 避ける |
|---|---|---|
| ミッション | 提唱価値と実態が一致している | スローガン先行・理念形骸化 |
| 仕事内容 | 構造設計・改善・再現性構築 | 短期KPI追いのみ |
| 組織 | 機能横断で動ける | Silo固定・政治依存 |
| 評価 | 成果と影響で見てくれる | 年功・忖度重視 |
| 顧客観 | 人として尊重している | リソース扱い |

## 転職判断ロジック
**GO条件**:
- RevOps / BizOps / GTMの実質的な責任を持てる
- 顧客体験と収益が連動している組織
- "なぜ" を問える文化

**STOP条件**:
- 提唱価値と実態のGAPが大きい（かつ改善意欲がない）
- 売上最優先で顧客期待を毀損する意思決定が常態化
- 人をリソース扱いするカルチャー

## 積み上げるべきスキルセット
- [ ] Revenue Architecture設計経験
- [ ] CRM / MA / CS Toolの実装設計
- [ ] Sales / CS / Marketingのハンドオフ設計
- [ ] Win-Loss分析と改善サイクル
- [ ] BI / データダッシュボード設計
