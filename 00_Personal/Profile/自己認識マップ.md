# Pina Profile — 自己認識マップ

## ソーシャルスタイル
**ドライバー × アナリティカル**
- 成果と正確性を両立させたい
- 感情より構造・論理で判断する
- "なぜやるか" が腹落ちしないと動けない

## FFS理論
**拡張性 × 弁別性**
- 物事の構造・矛盾・GAPに強く反応
- 広く収集して深く分類・整理する
- 表面的な答えに満足せず本質を追う

## MBTI
**INTP-A / INFJ-A傾向（I:61 / N:60 / T:70 / P:60）**
- 内省と概念思考が優位
- パターン認識と抽象化が得意
- 細部より構造・原理の把握を優先

## ストレングスファインダー
1. **回復志向** — 問題・矛盾を見つけて是正したい
2. **収集心** — 情報・知識・パターンを蓄積する
3. **学習欲** — 領域横断で高速に知識統合する
4. **コミュニケーション** — 抽象を具体に翻訳できる
5. **自我** — 自分の影響と貢献を重視する

## 核心的関心領域
> 「提唱価値を期待以上で実装し、その価値体験が信頼・継続利用・推奨へ連鎖していく事業構造」

- **Brand構造** = 見せ方ではなく、価値約束と実態の一致
- **Revenue** = 顧客信頼の蓄積から生まれるもの
- **GTM/CX/Ops** = 分断せず一貫して設計する

## Strength パターン
- 構造的矛盾の検知
- 表面施策より本質原因を掘り下げる
- 現場理解 ↔ 抽象思考の往復
- 提唱価値と実態の一致への執着

## Weakness・注意点
- 言行不一致・理念形骸化へのストレス耐性低
- 政治・調整で消耗しやすい
- "なぜ" が腹落ちしないとエネルギーが出ない
- 改善余地を見ると深入りしすぎる

## 志向するキャリア
RevOps / BizOps / GTM / Customer Transformation
→ 最終: CRO / CSO / 事業責任者（価値提供×Revenue×CX統合）

## 理解・コミュニケーションの特性（2026-07-12追記）
- 暗記や「知ってる感」ではなく、**構造の腑落ち**で理解するタイプ
- 定義が正確であること、仕組み・背景（なぜそうなっているか）が筋道立っていることへの強いこだわり
- 本人曰く「学校教育的な頭の良さ・理解力があるわけではないが偏屈」— 知識量の問題ではなく、理解の入り口が"構造"にあるという特性
- 技術的な仕組み（フロント/バックエンドのコードなど）には明るくない（本人曰く「AI原始人」）ため、専門用語だけで説明せず、比喩・図解・因果関係を省略しない咀嚼が必要
- 分かった風の説明で誤魔化されることを最も嫌う。多少くどくても、AとBの間の繋がりを飛ばさない説明の方が信頼される
