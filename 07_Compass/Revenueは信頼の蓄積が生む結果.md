# Revenue = 信頼の蓄積が生む結果

## 命題
> "持続的なRevenueは、顧客に対する信頼残高（Trust Balance）の結果として生まれる"

売上を「獲得するもの」ではなく「信頼が変換されるもの」として見る。

## 信頼残高モデル

```
Trust Balance Account
    入金: 期待超過の価値提供、誠実な対応、問題解決
    出金: 期待裏切り、誠実でない対応、放置
    
残高が高い → 継続・拡大・推奨
残高がゼロ → 解約・批判
```

## Revenue構造への示唆

### 短期Revenue（一時的）
- 値引き、プレッシャー営業、オーバープロミスで生まれる
- Trust Balanceを消費する
- 長期では逆効果

### 持続的Revenue
- 価値提供 → 信頼 → 継続 → 拡大 → 推奨 のサイクル
- Trust Balanceを蓄積しながら成長する
- NRR（Net Revenue Retention）> 100%が実現する

## 計測ポイント
| 指標 | 信頼との関係 |
|---|---|
| NRR | 信頼が拡大しているか |
| Churn Rate | 信頼が損なわれていないか |
| Expansion Revenue | 追加投資したいと思われているか |
| Referral Rate | 他者に薦めたいと思われているか |
| CSAT / NPS | 現時点の信頼残高 |

## 組織の財務戦略との接続
- ARR成長より先にNRR > 100%を実現するべき理由
  → 穴の空いたバケツに水を注ぐより先に穴を塞ぐ
- CAC < LTV × margin が持続可能な構造の最低条件
- LTVを伸ばすのはSalesではなくCS + Product

## 個人仮説
> "高いNRRは、その会社が顧客から本当に信頼されている唯一の証明"
